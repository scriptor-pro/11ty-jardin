# Grille de Conformité – Logement pour 1 Personne

> **Région de Bruxelles-Capitale**  
> *Exemple indicatif de vérification des normes minimales de salubrité, sécurité et équipement selon le Code bruxellois du logement.*

---

| **Critère**                                      | **Exigence minimale**                             | **Conforme ?** | **Observations**                      |
|--------------------------------------------------|---------------------------------------------------|----------------|----------------------------------------|
| **Surface habitable**                            | ≥ 28 m²                                           | ☑ Oui / ☑ Non  |                                        |
| **Hauteur sous plafond (pièces principales)**    | ≥ 2,20 m                                          | ☑ Oui / ☑ Non  |                                        |
| **Éclairage naturel suffisant**                  | Fenêtres vers l’extérieur                         | ☑ Oui / ☑ Non  |                                        |
| **Aération des pièces**                          | Naturelle ou mécanique conforme                   | ☑ Oui / ☑ Non  |                                        |
| **Installation électrique**                      | Conforme aux normes RGIE                          | ☑ Oui / ☑ Non  | Attestation de conformité requise     |
| **Sécurité incendie (détecteurs)**               | Détecteurs de fumée obligatoires                  | ☑ Oui / ☑ Non  | Obligatoires dans chaque étage        |
| **Chauffage**                                     | Suffisant, fixe, sûr et fonctionnel               | ☑ Oui / ☑ Non  | Pas de chauffage d’appoint interdit   |
| **Eau potable**                                  | Présence d’un point d’eau potable                 | ☑ Oui / ☑ Non  |                                        |
| **Équipements sanitaires**                       | WC + douche ou baignoire accessibles             | ☑ Oui / ☑ Non  | Peut être partagé dans certains cas   |
| **Cuisine ou coin cuisine**                      | Évier + plaques de cuisson + aération             | ☑ Oui / ☑ Non  |                                        |
| **Étanchéité / Toiture / Murs**                  | Pas d’infiltration d’eau ou humidité excessive    | ☑ Oui / ☑ Non  |                                        |
| **État général des murs/plafonds/sols**          | Pas de dégradation importante                     | ☑ Oui / ☑ Non  |                                        |
| **Ventilation des pièces humides**               | Système de ventilation adapté                     | ☑ Oui / ☑ Non  |                                        |

---

## Utilisation
- Destiné à un usage indicatif pour vérification de base.
- Pour une évaluation officielle, contactez un organisme agréé (ex. Bruxelles Logement, architecte).
