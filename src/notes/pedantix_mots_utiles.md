# Pédantix — 10 mots les plus utiles

Mots à fort pouvoir discriminant pour identifier rapidement le domaine d'une page Wikipédia.

| # | Mot | Indice fourni |
|---|-----|---------------|
| 1 | **est** | Révèle la structure syntaxique ("X est un/une…") |
| 2 | **français** / **française** | Indique si le sujet est lié à la France |
| 3 | **siècle** | Révèle si c'est un sujet historique et quelle époque |
| 4 | **né** / **née** | Confirme que c'est une biographie |
| 5 | **guerre** | Contexte militaire ou historique |
| 6 | **ville** | Distingue géographie vs autre domaine |
| 7 | **film** | Distingue cinéma vs autre art |
| 8 | **prix** | Révèle récompenses, distinctions, Nobel… |
| 9 | **monde** | Sujet à portée internationale |
| 10 | **album** | Distingue musique vs autres domaines |

## Stratégie

1. Commence par `siècle`, `né`, `film`, `français`, `guerre` pour cerner le domaine.
2. Une fois le domaine identifié (personne / lieu / œuvre / événement), affine avec des mots spécifiques.
3. Évite les mots outils (le, la, de, et…) — Pédantix les ignore généralement.
