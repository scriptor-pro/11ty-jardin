# Le mystère des polices accentuées


J'avais un problème de caractères accentués avec le terminal [Ptyxis](https://gitlab.gnome.org/chergert/ptyxis?ref=itsfoss.com). 

J'ai changé de police de caractères, ça n'a pas arrangé le problème. 

## Ca se passe dans le profil


J'ai été voir si, par hasard, le problème ne venait pas de mon profil et... bingo. 

Avec Caractères de largeur ambigüe sur "étroit", ça a tout de suite été beaucoup mieux.
